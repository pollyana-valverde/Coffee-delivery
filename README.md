# Café delivery - Site React

Este é um site React puro para a cafeteria Café Aroma, com páginas para Home, Sobre Nós, Produtos e Contato. O projeto conta a história de uma família apaixonada por café, desde suas origens até os produtos oferecidos.

## Funcionalidades

- Navegação entre páginas usando React Router
- Design responsivo e acessível
- Conteúdo coerente e narrativo sobre a cafeteria

## Como executar

1. Instale as dependências: `npm install`
2. Execute o servidor de desenvolvimento: `npm run dev`
3. Abra http://localhost:5173 no navegador

## Estrutura do Projeto

- `src/pages/`: Páginas do site (Home, About, Products, Contact)
- `src/components/`: Componentes reutilizáveis (Header, Navbar, Footer)
- `src/App.jsx`: Componente principal com roteamento
- `src/App.css`: Estilos globais
